# Графики

> 🇬🇧 [This page in English](../en/charts.md) · [← Оглавление документации](README.md)

Нажмите `V` на любом столбце, чтобы построить график. Что именно вы получите,
зависит от типа столбца и от того, **закрепили** ли вы опорный столбец через `!`.

![Графики — гистограмма и сгруппированный столбчатый](https://raw.githubusercontent.com/denisotree/tuitab/master/.github/assets/charts.gif)

## Типы графиков

| Столбец под курсором | Закреплённый столбец (`!`) | График |
|----------------------|----------------------------|--------|
| Числовой | — | **Гистограмма** (интервалы Фридмана–Дьякониса) |
| Категориальный | — | **Столбчатый график частот** |
| Числовой | Дата / Дата-время | **Линейный график** (выбор агрегации) |
| Категориальный | Дата / Дата-время | **Линейный график** (количество по времени) |
| Числовой | Категориальный | **Сгруппированный столбчатый** (выбор агрегации) |

Когда график агрегирует, небольшое окно спрашивает как:
**Sum · Count · Avg · Median · Min · Max**. Выбор — `j` / `k` и `Enter`.

## Как закрепление меняет график

Закрепление (`!`) задаёт **опорную ось**:

- Закрепите столбец-**дату**, переведите курсор на **числовой** столбец, нажмите
  `V` → линейный график значения по времени.
- Закрепите столбец-**категорию** (например, region), переведите курсор на
  **числовой** столбец, нажмите `V` → сгруппированный столбчатый график (по
  столбику на категорию).
- Ничего не закрепляйте и нажмите `V` → гистограмма (числовой) или график частот
  (категориальный) только для столбца под курсором.

Открепить — снова `!`. О закреплении см. [горячие клавиши](keybindings.md).

## Внутри графика

| Клавиша | Действие |
|---------|----------|
| `h` `k` / `←` `↑` | Выбрать предыдущий столбик / точку |
| `l` `j` / `→` `↓` | Выбрать следующий столбик / точку |
| `Enter` | **Детализация** — отфильтровать таблицу до строк выбранного столбика |
| `V` / `q` / `Esc` | Закрыть график |

Каждый столбик подписан своим значением, а график автоматически переключается
между вертикальной и горизонтальной раскладкой в зависимости от длины подписей
категорий.

## Примеры

```sh
tuitab sales.csv     # столбцы: date, region, category, units, revenue
```

- **Распределение выручки** — встаньте на `revenue`, нажмите `V`. Появится
  гистограмма с интервалами Фридмана–Дьякониса.
- **Выручка по регионам** — закрепите `region` через `!`, встаньте на `revenue`,
  нажмите `V`, выберите **Sum**. Появится сгруппированный столбчатый график.
- **Выручка по времени** — закрепите `date` через `!`, встаньте на `revenue`,
  нажмите `V`, выберите **Sum**. Появится линейный график.
- **Структура категорий** — встаньте на `category`, нажмите `V` для графика
  частот.
