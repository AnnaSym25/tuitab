# Начало работы

> 🇬🇧 [This page in English](../en/getting-started.md) · [← Оглавление документации](README.md)

## Установка

Самый быстрый способ — через Cargo:

```sh
cargo install tuitab
```

Устанавливаются три одинаковые команды — `tuitab` и более короткие псевдонимы
`ttab` и `ttb`. Остальные способы (Homebrew, AUR, Debian, готовые сборки)
описаны в [основном README](https://github.com/denisotree/tuitab/blob/master/README.md#installation).

## Открыть файл

Передайте поддерживаемый файл первым аргументом:

```sh
tuitab data.csv
tuitab report.parquet
tuitab books.xlsx
tuitab app.db
```

| Формат | Расширения | Примечания |
|--------|-----------|------------|
| CSV / TSV | `.csv`, `.tsv` | Разделитель определяется автоматически; задаётся через `-d` |
| JSON | `.json` | Массив объектов или построчный JSON |
| Parquet | `.parquet` | Колоночный, быстрый |
| Excel | `.xlsx`, `.xls` | Книги с несколькими листами открываются списком листов |
| SQLite | `.sqlite`, `.sqlite3`, `.db` | Таблицы открываются списком таблиц |
| DuckDB | `.duckdb`, `.ddb`, `.db` | `.db` сначала пробуется как SQLite, затем как DuckDB |

Для книг и баз данных tuitab сначала показывает обзор (листы или таблицы);
нажмите `Enter` на строке, чтобы открыть её, и `Esc` / `q`, чтобы вернуться.

### Задать разделитель

Когда автоопределение ошибается (или файл разделён `;`):

```sh
tuitab data.csv -d ';'
```

## Просмотр нескольких файлов

Передайте больше одного пути — и tuitab откроет **список файлов** вместо одной
таблицы:

```sh
tuitab orders.csv customers.csv products.parquet
```

Каждый файл становится строкой с именем, размером и временем изменения. `Enter`
открывает выделенный файл; `Esc` / `q` возвращает к списку.

## Просмотр каталога

Укажите tuitab папку (или запустите без аргументов, чтобы взять текущую):

```sh
tuitab ./reports/
tuitab               # текущий каталог
```

Откроется навигатор по файлам — открывайте файлы по `Enter`, выходите назад по
`Esc` / `q`.

## Чтение из конвейера

tuitab читает stdin, когда данные передаются по конвейеру. Укажите формат через
`-t`:

```sh
cat data.csv | tuitab -t csv
psql -c "SELECT * FROM orders" --csv | tuitab -t csv
echo '[{"id":1,"name":"Alice"}]'   | tuitab -t json
```

Из stdin понимаются `csv`, `tsv`, `txt` и `json` (`txt` обрабатывается как CSV).
Чтобы прочитать Parquet, Excel, SQLite или DuckDB, открывайте файл по пути, а не
через конвейер.

## Экран

```text
┌ sample.csv ───────────────────────────────────────┐
│  id  s│ name        s│ age #│ salary  ~│ department s│   ← строка заголовка (имя + значок типа)
│▌ 1    │ Alice Johnson│ 30   │ 75000.00 │ Engineering │   ← строка под курсором (подсвечена)
│  2    │ Bob Smith    │ 45   │ 92000.50 │ Management  │
│  …                                                  │
├─────────────────────────────────────────────────────┤
│ NORMAL   Loaded 20 rows                  row 3/20 col 3/5 │  ← строка состояния
└─────────────────────────────────────────────────────┘
```

- В **заголовке** для каждого столбца показано имя и небольшой **значок типа**
  (`s` строка, `#` целое, `~` дробное, `d` дата, `t` дата-время,
  `%` проценты, `$` валюта, `B` размер файла, `?` логический).
- В **строке состояния** виден текущий режим, сообщение и позиция.
- В любой момент нажмите `?`, чтобы открыть встроенную справку.
