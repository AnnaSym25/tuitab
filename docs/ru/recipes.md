# Рецепты

> 🇬🇧 [This page in English](../en/recipes.md) · [← Оглавление документации](README.md)

Короткие практические приёмы. Полный список клавиш — в
[Горячих клавишах](keybindings.md).

## Свести столбец

- **Статистика** — нажмите `I` для листа сводки: количество, пропуски,
  уникальные, минимум, максимум, среднее, медиана, мода, стандартное отклонение
  и квантили по столбцам.
- **Частоты** — нажмите `F` для подсчёта значений столбца под курсором.
  Закрепите несколько столбцов и нажмите `gF` для частот по нескольким столбцам.
- **Агрегатор-итог** — нажмите `+`, выбирайте по `Space` (сумма, среднее,
  медиана, количество, уникальные, перцентили, минимум, максимум, …). Очистка —
  `-`.
- **Быстрый итог** — нажмите `Z`, чтобы свести видимые / выделенные значения в
  строку состояния.

## Найти и удалить дубликаты

- **Подсветить дубликаты** — `Shift+S`, затем `d` выберет все строки, у которых
  есть дубликат.
- **Оставить по одной на группу** — `Shift+S`, затем `D` сделает умную
  дедупликацию; если есть закреплённые столбцы, спросит критерий, какую строку
  оставить.
- **Убрать по ключу** — закрепите ключевые столбцы, затем `gD` оставит первую
  строку в каждой группе.
- После выбора нажмите `d`, чтобы удалить, или `"`, чтобы вынести выделение на
  новый лист.

## Посчитать долю от итога

- **% от итога** — на числовом столбце нажмите `zf`, чтобы добавить столбец
  «% от итога».
- **% внутри групп** — нажмите `zF`, выберите столбцы разбиения и получите
  столбец доли в группе.

## Перестроить

- **Транспонировать строку** — нажмите `Enter`, чтобы развернуть текущую строку
  в вид Столбец / Значение (удобно для широких записей).
- **Транспонировать таблицу** — нажмите `T`, чтобы поменять местами строки и
  столбцы; нажмите `T` снова, чтобы отменить.
- **Сводная** — см. [Сводные таблицы](pivot.md).
- **Случайная выборка** — `Shift+S`, затем `r`, введите количество строк.

## Редактировать данные

- **Одна ячейка** — нажмите `e` (или `E`, чтобы открыть её в `$EDITOR`).
- **Много строк сразу** — выделите строки, затем `ge`, чтобы задать всем одно
  значение.
- **Переименовать столбец** — `ze`. **Удалить** — `zd`. **Вставить пустой** —
  `zi`.
- **Найти и заменить** — `zr` (буквально) или `zg` (регулярное выражение) в
  столбце.
- **Разбить столбец** — `zx`, затем введите разделитель.
- **Знаки после запятой** — `z.` больше, `z,` меньше.

## Задать типы столбцов

Нажмите `t`, чтобы выбрать тип: строка, целое, дробное, дата, дата-время,
логический, проценты, валюта или размер файла. При выборе **Currency** можно
указать **USD · EUR · GBP · JPY**, и столбец отформатируется нужным символом.

## Скопировать в буфер обмена

| Клавиши | Что копирует |
|---------|--------------|
| `yc` | Текущую ячейку |
| `yr` | Выделенные строки (или текущую) — выбрать TSV / CSV / JSON / Markdown |
| `yz` | Столбец под курсором для выделенных строк |
| `yZ` | Весь столбец под курсором |
| `yR` | Всю таблицу — выбрать TSV / CSV / JSON / Markdown |

Отметьте столбцы через `zs`, чтобы включить в `yr` / `yR` только их. Вставить
строки обратно — `p`.

## Экспортировать в файл

Нажмите `Ctrl+S` и введите путь. Формат определяется расширением:

| Расширение | Формат |
|------------|--------|
| `.csv` / `.tsv` | CSV / TSV |
| `.parquet` | Parquet |
| `.json` | JSON |
| `.xlsx` | Excel |
| `.db` / `.sqlite` / `.sqlite3` | SQLite |

`Tab` дополняет путь. Отменить правку — `U`, повторить — `Ctrl+R`, перечитать с
диска — `R`.

## Отфильтровать до нужного

- **Поиск** — `/` подсвечивает ячейки по регулярному выражению; `n` / `N` для
  перехода.
- **Выбор по значению** — `,` выбирает строки, равные текущей ячейке.
- **Выбор выражением** — `|`, затем `!=expr`, например `|!=amount > 1000`
  (см. [Выражения](expressions.md)).
- Затем `"`, чтобы сделать лист из выделения, или `d`, чтобы удалить его.
