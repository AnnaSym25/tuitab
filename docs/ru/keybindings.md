# Горячие клавиши

> 🇬🇧 [This page in English](../en/keybindings.md) · [← Оглавление документации](README.md)

Полный справочник команд. Нажмите `?` в tuitab для встроенной шпаргалки.
Все клавиши ниже — для **обычного режима** (Normal), если не указано иное. Многие
команды действуют на **столбец под курсором** или на **выделенные строки**.

## Навигация

| Клавиша | Действие |
|---------|----------|
| `h` `j` `k` `l` / стрелки | Переместить курсор влево / вниз / вверх / вправо |
| `gg` | Перейти к первой строке |
| `G` / `End` | Перейти к последней строке |
| `Home` | Перейти к первой строке |
| `Ctrl+F` / `PageDown` | Страница вниз |
| `Ctrl+B` / `PageUp` | Страница вверх |
| `q` / `Esc` | Выход — или возврат на один лист назад, если вы углубились |

## Сортировка

| Клавиша | Действие |
|---------|----------|
| `[` | Сортировать по возрастанию по столбцу под курсором |
| `]` | Сортировать по убыванию по столбцу под курсором |
| `r` | Вернуть исходный порядок строк |

## Поиск и выбор строк

| Клавиша | Действие |
|---------|----------|
| `/` | Поиск — подсвечивает ячейки по регулярному выражению |
| `n` / `N` | К следующему / предыдущему совпадению |
| `c` | Снять подсветку поиска |
| `,` | Выбрать строки, где ячейка равна текущему значению |
| `\|` | Выбрать строки по регулярному выражению или по выражению с префиксом `!=` (например, `\|!=age > 30`) |
| `s` / `u` | Выбрать / снять выбор текущей строки |
| `gs` / `gu` | Выбрать все / снять выбор со всех строк |
| `gt` | Инвертировать текущее выделение |
| `Shift+S` `r` | Выбрать **N** случайных строк |
| `Shift+S` `d` | Выбрать все строки, у которых есть дубликаты |
| `Shift+S` `D` | Умная дедупликация — оставляет по одной строке на группу (спросит критерий, если есть закреплённые столбцы) |
| `d` | Удалить выделенные строки |
| `"` | Создать новый лист из выделенных строк |

Язык фильтра `|!=` описан в [Выражениях](expressions.md).

## Столбцы

| Клавиша | Действие |
|---------|----------|
| `!` (`Shift+1`) | Закрепить / открепить столбец (остаётся виден при прокрутке; используется графиками и сводными) |
| `_` | Перебрать ширину столбца |
| `g_` | Перебрать ширину всех столбцов |
| `=` | Добавить вычисляемый столбец из [выражения](expressions.md) |
| `t` | Открыть меню **типа** столбца (строка, целое, дробное, дата, дата-время, логический, проценты, валюта, размер файла) — при выборе **Currency** можно указать USD / EUR / GBP / JPY |
| `+` | Добавить агрегатор-итог по столбцу (множественный выбор по `Space`) |
| `-` | Очистить агрегаторы столбца |
| `Z` | Быстрая агрегация видимых / выделенных значений в строку состояния |

### Операции со столбцами (префикс `z`)

| Клавиша | Действие |
|---------|----------|
| `ze` | Переименовать столбец |
| `zd` | Удалить столбец |
| `zi` | Вставить пустой столбец |
| `zs` / `zu` | Отметить / снять отметку столбца (отмеченные показаны с `*` и учитываются при копировании) |
| `z←` / `zh` | Сдвинуть столбец влево |
| `z→` / `zl` | Сдвинуть столбец вправо |
| `z.` / `z>` | Увеличить число знаков после запятой |
| `z,` / `z<` | Уменьшить число знаков после запятой |
| `zf` | Добавить столбец «% от итога» |
| `zF` | Добавить столбцы «% от итога» по разбиению (выберите столбцы разбиения) |
| `zr` | Найти и заменить текст в столбце |
| `zg` | Найти и заменить по регулярному выражению |
| `zx` | Разбить столбец по разделителю |
| `zEnter` | Провалиться в узел из текущей ячейки (JSON/YAML/TOML) |

## Строки, листы и аналитика

| Клавиша | Действие |
|---------|----------|
| `Enter` | Транспонировать текущую строку в вид Столбец/Значение (детализация); на листе JSON/YAML/TOML — провалиться в узел строки |
| `T` | Транспонировать всю таблицу (повторное нажатие отменяет) |
| `I` | Сводка по листу — статистика по столбцам |
| `F` | Таблица частот для столбца под курсором |
| `gF` | Таблица частот по нескольким столбцам (группирует по закреплённым) |
| `gD` | Дедупликация по закреплённым столбцам (оставляет первую строку в группе) |
| `V` | [График](charts.md) столбца под курсором |
| `W` | [Сводная таблица](pivot.md) |
| `J` | [JOIN](join.md) с другой таблицей |
| `e` | Редактировать текущую ячейку |
| `E` | Редактировать текущую ячейку в `$EDITOR`; на листе JSON/YAML/TOML ячейка-контейнер открывается как настоящее поддерево — можно добавлять, удалять и переставлять ключи |
| `m` | Переключить проекцию текущего узла: записи / ключ-значение / скаляры |
| `ge` | Массовое редактирование — задать одно значение всем выделенным строкам |

## Буфер обмена (префикс `y`)

| Клавиша | Действие |
|---------|----------|
| `yc` | Скопировать текущую ячейку |
| `yr` | Скопировать выделенные строки (или текущую) — выбрать формат |
| `yz` | Скопировать столбец под курсором для выделенных строк — выбрать формат |
| `yZ` | Скопировать весь столбец под курсором — выбрать формат |
| `yR` | Скопировать всю таблицу — выбрать формат |
| `p` | Вставить строки из буфера обмена |

Копии строк/таблицы предлагают **TSV · CSV · JSON · Markdown**; копии столбца —
разделение переводом строки, запятой или запятой с кавычками. `yr` и `yR`
учитывают столбцы, отмеченные через `zs`.

## Файл

| Клавиша | Действие |
|---------|----------|
| `Ctrl+S` | Сохранить / экспортировать / конвертировать (CSV, TSV, Parquet, JSON, JSONL, YAML, TOML, Excel или SQLite) |
| `R` | Перечитать файл с диска |
| `U` / `Shift+U` | Отменить (до 50 шагов) |
| `Ctrl+R` | Повторить |
| `?` | Показать / скрыть справку |

## Режим графика

| Клавиша | Действие |
|---------|----------|
| `h` `k` / `←` `↑` | Предыдущий столбик / точка |
| `l` `j` / `→` `↓` | Следующий столбик / точка |
| `Enter` | Детализация по выбранному столбику |
| `V` / `q` / `Esc` | Закрыть график |

## Режимы ввода

Когда вы вводите текст в поле (поиск, выражение, формула сводной,
переименование, путь сохранения, …):

| Клавиша | Действие |
|---------|----------|
| `←` `→` `Home` `End` | Перемещение текстового курсора |
| `Backspace` / `Delete` | Удалить слева / справа |
| `Tab` | Автодополнение (имена столбцов / пути к файлам, где доступно) |
| `↑` / `↓` | Предыдущая / следующая запись истории (поля выражения и сводной) |
| `Enter` | Применить |
| `Esc` | Отменить |


## Листы JSON / YAML / TOML

Эти форматы открываются как таблица поверх настоящего документа, а не как его
плоская копия.

| Клавиша | Действие |
|---------|----------|
| `Enter` | Провалиться в узел текущей строки |
| `zEnter` | Провалиться в узел текущей ячейки |
| `q` / `Esc` | Подняться на уровень выше |
| `m` | Переключить проекцию: записи / ключ-значение / скаляры |
| `e` | Правка скаляра — тип сохраняется, строка остаётся строкой |
| `E` | Правка контейнера как текста в `$EDITOR` (добавить, удалить, переставить ключи) |
| `Ctrl+S` | Сохранить; другое расширение конвертирует формат |

Все листы одной цепочки погружения работают с одним документом, поэтому правка на
третьем уровне видна при возврате наверх, а `U` откатывает её на любом уровне.

Сохранение пересериализует документ целиком: вложенность, порядок ключей и даты TOML
сохраняются. Комментарии и исходное форматирование — нет, они не часть разобранного
документа.

## Раскладки клавиатуры

Раскладки, отличные от QWERTY — **ЙЦУКЕН** (русская), **QWERTZ** (немецкая) и
**AZERTY** (французская) — прозрачно переназначаются на позиции QWERTY, поэтому
горячие клавиши работают без переключения раскладки.
